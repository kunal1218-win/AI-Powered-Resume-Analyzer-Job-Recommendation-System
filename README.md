# 🤖 AI-Powered Resume Analyzer & Job Recommendation System

## 📌 About the Project
An AI-powered web application designed to analyze resumes, identify skills, recommend suitable job roles, and highlight skills that users can improve.

## 🎯 Objectives
- Extract skills from uploaded resumes.
- Analyze resume compatibility with job requirements.
- Recommend suitable job roles.
- Identify missing or recommended skills.
- Help students explore career opportunities.

## ✨ Planned Features
- Resume upload (PDF)
- Automatic skill extraction
- Resume compatibility scoring
- Job role recommendations
- Skill gap analysis
- Interactive web dashboard

## 🛠️ Technologies
- **Language:** Python
- **Data Processing:** Pandas, NumPy
- **Machine Learning:** Scikit-learn
- **NLP:** TF-IDF, Cosine Similarity
- **Backend:** Flask
- **Frontend:** HTML, CSS, JavaScript
- **Dataset:** CSV
